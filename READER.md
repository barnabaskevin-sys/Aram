# அறம் · Aram Reader

The **Reader** is the offline edition of Aram: verse of the day, **Check** (match a pasted verse against the library, then run the Yāppu metre check), and the **Library** with kolams, in 45 interface languages with day and night themes. It needs no AI and no account. Ask and Explain are switched off in this edition.

The published page is built from the same source as the full app. `aram-reader.html` here is that exact page (one self-contained file, about 7.7 MB). Open it in any browser to use it.

## Layout

```
aram-reader.html      the finished Reader page (built from the files below)
app/body.html         page markup
app/css/              palm-leaf theme (aram.css) and bundled fonts css
app/modules/*.js      app source: views, card, check, library, sheets, lang, init, ...
app/i18n/*.js         interface text, 45 languages (English is the master)
app/js/engine.js      Yāppu engine (metre check and kolam)
app/js/data.js        the verse corpus (see NOTICE.md for the sources and their licence)
app/js/app.js         generated by tools/assemble_app.py, do not edit by hand
src/app.js            base that assemble_app.py patches
tools/                build, assemble, translation validator, layout sweep
```

The source folder is called `modules`, not `parts`, because a Python-style `.gitignore` skips any directory named `parts/`.

## Rebuild

Needs only Python 3.

```
python3 tools/assemble_app.py    # after editing app/modules/*.js -> writes app/js/app.js
python3 tools/build.py reader    # -> aram-reader.html
python3 tools/build.py www       # -> www/ (the installable web build)
node tools/validate_i18n.js      # checks every language has every key
```

`tools/sweep.py` and `tools/shot.py` use Playwright for screenshots and a layout check per language.

The Reader differs from the full app by one flag in the build: `window.ARAM_CONFIG = {reader: true}`, which adds the `reader` class to `<body>` and hides the AI screens with CSS (see the end of `app/css/aram.css`).

## Texts

The verse texts come from public sources, mainly Project Madurai, which asks that its header be kept intact. Read `NOTICE.md` before distributing.
