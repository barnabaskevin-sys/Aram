# அறம் · Aram

*Tamil wisdom, one verse at a time. A tool for knowing life better.*

**Aram** (அறம், "virtue", the first of the three parts of the Thirukkural) is a reader for classical Tamil literature. It holds **18,865 verses and passages** on 15 shelves. For any verse it can draw a **kolam**, run a **metre check**, and tell you whether a quotation you found online is genuine. The interface comes in **45 languages** and is designed as a palm-leaf manuscript, with a day leaf and a night lamp theme.

It is a static web app: no server, no database, no account. Everything runs in the browser, and after the first visit it works offline.

| Screen | What it does |
|---|---|
| **Home** | A verse of the day, with a button for another one. |
| **Check** | Paste a verse you saw somewhere. It is matched against every verse in the library: exact, part of a verse, close variant (differing words are marked) or not found. Then it goes through the Yāppu metre check. |
| **Library** | Browse each work chapter by chapter. Every verse has its kolam and its metre result. |
| **Settings** | App language (45, including right-to-left Arabic, Hebrew, Persian and Urdu), day or night theme, text size, texts and credits. |

**Shelves:** Thirukkural, Nālaṭiyār, Auvaiyār, the Eighteen Minor Works, Tolkāppiyam, Puṟanāṉūṟu, Kuṟuntokai, Akanāṉūṟu, Kalittokai, Patiṟṟuppattu, Cilappatikāram, Maṇimēkalai, Tēvāram, Tirumantiram and Tiruvācakam.

## Quick start

You need [Node.js](https://nodejs.org) 20 or newer.

```
npm install
npm run dev          # http://localhost:5173, reloads as you edit
```

To try the production build (with the offline cache) locally:

```
npm run build        # writes dist/
npm run preview      # http://localhost:4173
```

## Deploy

The repository is ready for **Vercel**: import it, keep the detected settings (framework Vite, build `npm run build`, output `dist`), deploy. See **[Deployment](docs/DEPLOYMENT.md)**.

## How it works

- **Yāppu** is a programming language in which every program is a valid *venba*, a Tamil verse form with strict rules of metre. Its engine (`src/engine/yappu.js`) scans a verse's syllables and decides whether it follows the rules. Aram uses the same engine for the "Passes the Yāppu metre check" line on each verse and for the kolam drawn beside it.
- **The corpus** (`src/data/verses.json`) is a separate file with a content hash in its name. The page shows its frame at once, fetches the corpus, and searches it in the browser. Browsers keep it for a year and fetch it again only when it changes.
- **Offline:** a service worker (generated by `vite-plugin-pwa`) stores every built file on the first visit, so the app opens and works with no connection afterwards. It can be installed on a phone's home screen.

## Status and limits

- **Translations:** the 44 languages besides English were written with AI help. They pass automatic checks (every key present, placeholders intact, right script) but no native speaker has read them. Get that review for the languages you plan to promote.
- **Ask (AI questions and meanings)** was part of an earlier version and is not in this one, since it needs a server. The interface dictionaries still hold its text, so it can come back without new translations; the earlier code is in the Git history (commit `013d8e7`).
